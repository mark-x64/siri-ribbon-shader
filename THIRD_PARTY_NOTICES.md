# Third-party material

`public/media/reference.mp4` is a 3.6-second excerpt from Apple's Siri AI retail video. Its audio track and metadata have been removed; the video is included for comparison with the procedural reconstruction.

The GitHub Pages and default production builds exclude this file and the comparison controls. The reference is available only in the explicitly selected local `npm run dev:reference` mode.
